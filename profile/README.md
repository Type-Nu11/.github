## Development Status

Pingdom은 현재 **SNAPSHOT 개발 단계**에 있습니다.

서비스의 핵심 기능과 구조가 지속적으로 변경되고 있어  
현재는 다음 정보를 외부에 공개하지 않습니다.

- 기술 스택 및 시스템 구성
- 애플리케이션 아키텍처
- API 명세와 데이터 구조
- 인프라 및 배포 환경
- 내부 기술 문서

관련 정보의 공개 범위는 서비스 안정화와 정식 출시 이후 검토할 예정입니다.

## Repository Policy

Pingdom의 소스 코드 저장소는 현재 모두 **Private Repository**로 운영됩니다.

개발 안정성과 내부 구현 보호를 위해 소스 코드, 커밋 기록,  
Issue 및 프로젝트 진행 내역에 대한 외부 접근은 제공하지 않습니다.

저장소 공개 여부와 시점은 향후 서비스 운영 정책에 따라 결정됩니다.
